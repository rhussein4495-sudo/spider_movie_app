# 🕸️ Spider-Man: Brand New Day - Ticket Booking App

A modern, cinematic movie ticket booking application built with **Flutter**, inspired by the Spider-Man universe.

---

## 📱 App Overview

**Spider-Man: Brand New Day** is a lightweight Flutter app that provides a smooth, immersive ticket-booking experience featuring a dark theme, custom transitions, and an interactive seat-selection layout.

---

## 🚀 App Flow & Screens

1. **Welcome Screen:** Cinematic entry point with the Spider-Man branding.
2. **Movie Details:** Displays artwork, description, duration, genre, release year, and rating, along with a ticket quantity slider.
3. **Seat Selection:** An interactive grid where users can pick their preferred seats with real-time counters.

---

## 🛠️ Built With

* **Framework:** Flutter
* **Language:** Dart
* **State Management:** `ValueNotifier`
* **UI/UX:** Custom Gradients, Sliders, and GridViews
